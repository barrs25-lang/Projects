# Adaptive Control of HMMWV
The files and reports in this directory represent a final project that implemented and tested an adaptive control law on an HMMWV model. This was tested in a high-fidelity physics engine (Chrono) using the python wrapper.

## Running the code
*Work in progress. In the meantime, follow instruction for Pychrono installation at* https://api.projectchrono.org/pychrono_installation.html

Must be in a python virtual environment with Pychrono configured correctly to run code from [main_cosim.py](UGV_Cosimulation_Chrono/main_cosim.py)
